# 🚀 Efe OS - Pardus XFCE Destekli Özel Mini İşletim Sistemi / Kontrol Merkezi

Kendi Linux (Pardus XFCE) ortamım üzerinde geliştirdiğim, Bash kabuğu ve Python (Tkinter) grafik arayüzlerini birleştiren özel bir kontrol merkezi ve mini uygulama ortamı! 

Bu proje; sıradan terminal pencerelerinden sıyrılarak kendi özelleştirilmiş araçlarını, hesap makinesini, şifre üreticisini ve sistem bilgi panellerini tek bir merkezden yönetebilmen için tasarlandı.
